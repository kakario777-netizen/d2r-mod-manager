# D2R 모드 정리기 (d2r-mod-manager)

디아블로2 레저렉션에 설치된 모드를 골라서, 안에 든 내용을 **기능 / 그래픽 / UI / 글자 / 사운드**로 나눠 보여 주고
그래픽만 골라 끌 수 있게 해 주는 윈도우 프로그램이에요.

- 그래픽 전부 끄기(기능만 살리기) 버튼 한 번으로 덮어쓰기 그래픽만 빼서 그래픽 메모리를 줄여요
- 새로 추가된 그림·그림 연결 파일은 빼면 튕길 수 있어서 일괄 끄기에서 자동으로 보호해요
- 게임 데이터(드랍·아이템·스킬 수치)는 잠가서 실수로 못 빼게 해요
- D2RLoader 플러그인·패치를 종류(기능/화면표시/그래픽/안정성)와 한글 설명과 함께 보여 주고 켜고 꺼요
- 처음 적용할 때 원본 모드를 `문서\D2R Mod Manager`에 자동 백업, 이후 변경 기록으로 어느 시점이든 되돌리기
- 게임 버전과 모드 기준 버전이 맞는지 표시
- 새 버전이 나오면 자동 업데이트

받기: [Releases](../../releases) 에서 `D2RModManager.exe`
